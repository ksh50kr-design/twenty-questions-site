# 스무고개 (Twenty Questions)

학생이 힌트를 하나씩 보면서 정답을 맞히는 정적 스무고개 웹사이트입니다.
서버(반)를 원하는 만큼 만들고 서버마다 다른 문제를 낼 수 있습니다. 빌드 과정 없이 순수 HTML/CSS/JS로만 되어 있어
GitHub Pages에 그대로 올리면 바로 동작합니다.

## 페이지 구성

| 주소 | 설명 |
|---|---|
| `index.html` | 시작 페이지. 학생이 자기 서버(반)를 고릅니다. **학생에게는 이 주소를 보내주세요.** |
| `play.html?server=ID` | 해당 서버의 게임 화면 |
| `editor.html` | 선생님용 편집 화면 (시작 페이지에는 링크가 없습니다. 주소를 직접 입력하세요). |
| `data/quiz.json` | 서버 목록과 서버별 문제가 모두 들어 있는 파일 |

## 서버와 문제 바꾸는 방법 (선생님)

1. `editor.html`에 들어갑니다.
2. 위쪽 탭에서 서버를 고르거나 **+ 서버 추가**로 새 서버를 만듭니다.
   - **서버 이름**을 원하는 대로 바꿀 수 있습니다. (예: `1반`, `방과후반`)
   - **◀ 앞으로 / 뒤로 ▶**로 시작 페이지에 보이는 순서를 바꿉니다.
   - **이 서버 삭제**로 서버를 없앱니다. (최소 1개는 남아야 합니다)
3. 서버마다 **정답**과 **힌트 10개**를 입력합니다.
   - 정답을 여러 형태로 인정하려면 쉼표로 구분합니다. 예: `이순신, 이순신 장군`
   - 채점할 때 띄어쓰기와 영문 대소문자는 무시합니다.
4. **미리 플레이**로 확인한 뒤 **quiz.json 다운로드**를 누릅니다.
5. GitHub 저장소의 `data` 폴더에서 `quiz.json`을 내려받은 파일로 교체합니다.
   (저장소 → `data` 폴더 → **Add file → Upload files** → 파일 끌어놓기 → **Commit changes**)
6. 1~2분 뒤 학생 화면에 반영됩니다.

편집 내용은 편집한 브라우저에 자동 저장되지만, 파일을 올리기 전까지 학생에게는 보이지 않습니다.
다른 컴퓨터에서 이어서 편집하려면 **quiz.json 불러오기**를 쓰거나, 사이트에 올라간 파일을 그대로 불러오면 됩니다.

## 게임 규칙 (학생)

- 힌트 1번부터 보이고, 매번 **정답**(답 입력 후) 또는 **다음**(다음 힌트 보기)을 고릅니다.
- 한 번이라도 틀리면 해당 문제는 끝나고, **정답과 남은 힌트 전체**가 공개된 뒤 다음 문제로 넘어갑니다.
- 10번째 힌트에서는 **다음** 대신 **포기** 버튼이 나옵니다.
- 점수: 힌트 1개 만에 맞히면 10점, 힌트를 하나 더 볼 때마다 1점씩 줄어듭니다. 틀리면 0점.
- **들어올 때마다 문제 순서 섞기**가 켜져 있으면 학생마다(그리고 다시 할 때마다) 순서가 달라집니다.

> 문제 파일(`data/quiz.json`)은 공개 파일이라, 주소를 알면 정답을 볼 수 있습니다.
> 수업용으로는 충분하지만 시험 용도로는 적합하지 않습니다.

## 로컬에서 미리보기

문제 파일을 불러오기 때문에 `index.html`을 더블클릭해서 열면 동작하지 않습니다.
간단한 정적 서버로 띄워주세요.

```bash
python -m http.server 8000
# http://localhost:8000 접속
```

## GitHub Pages로 배포하기

1. 이 폴더를 GitHub 저장소로 push 합니다.
2. 저장소 **Settings → Pages**에서 Source를 `main` 브랜치, `/ (root)` 폴더로 설정합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 시작 페이지가 보입니다.
