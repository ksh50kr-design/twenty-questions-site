시작 페이지 보기
문제 바꾸는 방법
  1. 서버를 추가·삭제하거나 이름을 바꾸고, 서버마다 정답과 힌트 10개를 입력합니다. (정답을 여러 형태로 인정하려면 쉼표로 구분: 이순신, 이순신 장군)
  2. 미리 플레이로 확인한 뒤 사이트에 반영을 누르면 1~2분 뒤 학생 화면에 적용됩니다.

편집 내용은 이 브라우저에 자동으로 저장되지만, 사이트에 반영을 누르기 전까지 학생에게는 보이지 않습니다.

GitHub 연결

처음 한 번만 설정하면 됩니다. GitHub 토큰을 만들어 아래에 붙여 넣으세요.

  1. 토큰 만들기 페이지를 엽니다. (GitHub 로그인 필요)
  2. Token name: 아무 이름(예: 스무고개), Expiration: 원하는 기간(최대 1년)
  3. Repository access: Only select repositories → 선택
  4. Permissions → Repository permissions → Contents: Read and write
  5. 맨 아래 Generate token → 나온 토큰(github_pat_로 시작)을 복사해 아래에 붙여 넣기

토큰은 이 브라우저에만 저장됩니다. 공용 컴퓨터라면 사용 후 연결 해제를 눌러주세요.
